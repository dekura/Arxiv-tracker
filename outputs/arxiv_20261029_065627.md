## 2610.37459 · M4Bench: Evaluating Procedural Specification for Clinical EHR Derivation Agents
*M4Bench：评估临床 EHR 衍生智能体的过程性规范*

- Hannes Ill, Rafi Al Attrach, Rajna Fani, Ahram Han, Ryohei Yamamoto, Marlene Louisa Moerig, Dukyong Yoon, Leo Anthony Celi · NeurIPS 2026
- [Abs](https://arxiv.org/abs/2610.37459v1) · [PDF](https://arxiv.org/pdf/2610.37459v1) · [Code1](https://github.com/hannesill/m4/tree/m4bench-neurips2026-camera-ready/benchmark) · [Code2](https://huggingface.co/datasets/hannesill/m4bench-evidence)
- **核心问题**：临床 EHR 衍生变量定义散落在条目编码、时间窗、缺失规则与输出粒度中，需检验编码智能体能否复现
- **关键困难**：现有基准缺少规范控制，无法区分收益来自规范完整性、交付格式还是模式熟悉与记忆
- **解决方案**：构建 28 个 MIMIC-IV/eICU 衍生任务，Docker 隔离运行 Codex，设无 skill、操作规范、诱饵 skill、原始参考 SQL、模式混淆等对照
- **主要结果**：skill 使奖励 +0.136（26/28 任务提升）；操作规范单独 +0.162，skill 仅再加 0.024；Claude Code 复现 +0.120
- **未来方向**：收益仅为与参考部分一致，严格检查全通过仅 25/280，行级 F1 几乎不变

## 2610.37434 · FeatureArc: Benchmarking Coding Agents on Evolving Features
*FeatureArc：面向演进式功能的编程智能体基准测试*

- Yunlong Wang, Alyssa Wu, Cuiyun Gao, Jia Feng, Songyuanyi Lu, Zhichao Hu
- [Abs](https://arxiv.org/abs/2610.37434v1) · [PDF](https://arxiv.org/pdf/2610.37434v1)
- **核心问题**：现有功能基准只在固定代码库上评测单次请求，无法检验智能体在自身早前代码上连续扩展功能
- **关键困难**：智能体后续阶段会继承早期缺陷且很少回查，在无外部测试反馈与回滚时错误难被发现
- **解决方案**：从仓库历史自动构建 2–10 阶的同功能任务，给出显式需求与接口契约，每阶段在参考代码上验证新行为 F2P 与旧行为 P2P 测试
- **主要结果**：73 个任务和 10 个智能体：成功率从首阶段 62.7% 降至整个功能的 28.5%，72.9% 的后期失败源于继承缺陷，约 95% 未被察觉
- **未来方向**：阶段之间无人工检查的自主功能演进仍是开放难题

*藏于明处：编码代理指令栈的实证研究*

- Felipe de Sant'Anna Paixão, Dhyego Tavares, Eduardo Almeida, Iftekhar Ahmed
- [Abs](https://arxiv.org/abs/2610.37332v1) · [PDF](https://arxiv.org/pdf/2610.37332v1)
- **核心问题**：编码代理发给模型的不只是用户提示，还含工具定义与环境上下文，该指令栈对用户不透明、研究刻画不足

- **解决方案**：在受控条件下解析各release首个模型请求的指令栈，比较组成与演化差异，并把4个开源代理的变更单元追溯到公开文档动机

- **未来方向**：建议随 release 公开捕获的指令栈与修订理由

## 2610.37224 · Spine: Compiling Subtask Trees into Structured Context for Long-Horizon Coding Agents
*Spine：将子任务树编译为结构化上下文，面向长时程编码智能体*

- Jiahong Xiang, Kunqiu Chen, Lingming Zhang, Yuqun Zhang
- [Abs](https://arxiv.org/abs/2610.37224v1) · [PDF](https://arxiv.org/pdf/2610.37224v1)
- **核心问题**：长时程编码任务的上下文随交互不断膨胀，而隐式裁剪或整体委派子任务会造成信息丢失或协调开销

- **解决方案**：同一智能体以内联方式执行嵌套子任务，仅并行独立任务才委派；运行时按完成状态保留未完成子任务交互、用结果替换已完成子任务细节，并保持前缀缓存复用

## 2610.37195 · Action-Value Calibration via Continuation Sharing for Long-Horizon Agentic Reinforcement Learning
*面向长时程智能体强化学习的续段共享动作价值校准（ConCal）*

- Yingjian Chen, Lang Zhou, Zixin Zhao, Pingfan Li, Weishi Zheng, Zhilin Zhao
- [Abs](https://arxiv.org/abs/2610.37195v1) · [PDF](https://arxiv.org/pdf/2610.37195v1) · [Code1](https://github.com/Yingjian-Chen/ConCal)
- **核心问题**：长时程智能体强化学习信用分配困难，单个动作的价值只能由一条采样续段估计，局部信用易受后续决策影响而失真
- **关键困难**：GiGPO 等方法虽在共享状态上比较动作，但每个动作价值仍来自单条采样续段，估计方差大且受轨迹后段决策干扰
- **解决方案**：按入向 state-action-state 转移匹配同一任务的多次访问，把共享续段证据与各访问自身转移估计结合，递归反向传播校准值以修正早期动作价值，且无需额外 rollout
- **主要结果**：使用 Qwen2.5-1.5B-Instruct 时，ALFWorld 与 WebShop 成功率较 GiGPO 分别提升 3.39 和 5.86 个百分点；留出回报诊断显示组内价值差误差更低、动作序一致性更高
