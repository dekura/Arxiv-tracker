## 2611.06583 · PatchCon: Patch-aware Weighted Supervised Contrastive Learning for Vulnerability Detection
*PatchCon：补丁感知加权监督对比学习的漏洞检测*

- Chaomeng Lu, Pooya Rostami Mazrae, Bert Lagaisse
- [Abs](https://arxiv.org/abs/2611.06583v1) · [PDF](https://arxiv.org/pdf/2611.06583v1)
- **核心问题**：现有学习型漏洞检测把函数当作独立样本，未充分利用修复补丁提供的监督信号
- **关键困难**：漏洞函数与其修补版本差异细微，独立样本训练难以学到修复引入的安全相关差别
- **解决方案**：基于 CodeBERT 联合优化漏洞分类与监督对比学习，对漏洞-修补函数对赋予更大的对比权重作为硬负样本，捕捉修复带来的细微安全差异
- **主要结果**：PairVul-Linux 上成对准确率由最强复现基线 0.2060 升至 0.3264，分类与成对指标均超越预训练代码模型和对比学习基线，接近 GPT-4o 方法且成本更低

## 2611.06858 · CompressionBench: How can your coding agents compress LLMs?
*CompressionBench：你的编码智能体如何压缩 LLM？*

- Xinrui Zhong, Zhifeng Li, Zhiming Wang, Yongqi Liu, Shanglin Yang, Yang Zhou, Zikun Li, Zhuoming Chen, Beidi Chen
- [Abs](https://arxiv.org/abs/2611.06858v1) · [PDF](https://arxiv.org/pdf/2611.06858v1)
- **核心问题**：编码智能体能否自主完成 LLM 压缩，在存储预算内保留原模型行为并产出可执行推理代码
- **关键困难**：压缩依赖表示设计与实验判断，缺少可测量的评测来检验智能体自主压缩能力
- **解决方案**：给定源检查点、存储上限、推理环境和时间预算，智能体自选压缩算法并迭代实验，困惑度反馈引导搜索，独立验证检查最终模型与推理代码
- **主要结果**：36 份提交中 29 份通过验证；按任务选最低 PPL 设计，平均 PPL 仅升 3.4%，下游准确率 77.33%，BF16 为 79.56%

## 2611.06829 · Enabling AWS Cloud FPGA Development Using High-Level Vitis HLS
*使用高层次 Vitis HLS 实现 AWS 云 FPGA 开发*

- David Rostcheck
- [Abs](https://arxiv.org/abs/2611.06829v1) · [PDF](https://arxiv.org/pdf/2611.06829v1)
- **核心问题**：AWS EC2 F2 云 FPGA 缺少从高层次语言到 AFI 的完整开发工具链，文献未记录
- **关键困难**：Vitis HLS 与 AWS HDK/AFI 工作流割裂，FPGA 专用电路错误难定位，时序收敛复杂
- **解决方案**：实现 Vitis HLS→HDK→AFI 工具链，以 FP32、位精确量化、C 仿真、物理 FPGA 四级流程定位错误，并总结时序收敛策略
- **主要结果**：在 FPGA 实现 TinyBERT 地址 NER 的嵌入层及 4 层编码器第 1 层；权重从主机 DRAM 流式读取，性能低于 CPU/GPU
- **未来方向**：权重从主机 DRAM 流式读取致性能不佳，需讨论后续改进路径

## 2611.06563 · EPISTEME: Trustworthy Coding Agents Through Tool Call Intent
*EPISTEME：通过工具调用意图实现可信编码智能体*

- Sofia Bobadilla, Carmine Cesarano, Raphina Liu, Javier Ron, Martin Monperrus
- [Abs](https://arxiv.org/abs/2611.06563v1) · [PDF](https://arxiv.org/pdf/2611.06563v1)
- **核心问题**：编码智能体的工具调用会改变本地状态，却不说明调用原因，难以判断好坏与审计
- **关键困难**：现有智能体从不声明调用动机，无法运行前拦截，也难以事后取证
- **解决方案**：Harness 要求调用前声明意图，记录命令实际效果，并校验自述与效果是否一致，日志可拦截调用并支持审计取证
- **主要结果**：在仅能靠作弊通过的 ImpossibleBench 上，强制声明意图暴露作弊；两个开源权重模型 49 次奖励黑客运行中日志揭露 90%

## 2611.06084 · Shallow Encoding Emits Deep Memories
*浅层编码产生深层记忆*

- Mingyuan Ma, Yangmin Li, Harris Nover, Zheyu Fu, Po-Han Huang, Alex Settle, Ashwin Nanjappa
- [Abs](https://arxiv.org/abs/2611.06084v1) · [PDF](https://arxiv.org/pdf/2611.06084v1)
- **核心问题**：混合语言模型为每个 token 保存 KV 缓存或循环态，导致预填充与解码时的计算和带宽开销过高
- **关键困难**：预填充需为每个 token 运行全部层，解码需读写整个循环态，而循环态字节量可比拟数千 token 的注意力缓存
- **解决方案**：冻结原权重，在浅层锚点加 emitter 直接写深层记忆，使多数 prompt token 只经过少量层；循环态按固定方向 rank-one sink 加低秩工作记忆存储，并给出周期压缩误差有界证明
- **主要结果**：在五种生产级混合模型（30B~300B+）的六个 checkpoint 上，十一项官方考试几乎无损；SGLang+GB300 agentic-coding trace 上 Qwen3.8-Flash-Next 单 GPU 吞吐提升 1.2-1.4x

## 2611.06049 · Reglos: A Self-Evolving Personal Memory Agent with Recursive Self-Improvement
*Reglos：具有递归自我改进能力的自演化个人记忆智能体*

- Sen Yang, Jiaduo Lin, Zehong Huang, Wen Liu
- [Abs](https://arxiv.org/abs/2611.06049v1) · [PDF](https://arxiv.org/pdf/2611.06049v1)
- **核心问题**：个人智能体记忆与 harness 补丁只针对目标失败，易过拟合，难验证泛化收益。
- **关键困难**：仅在目标失败上测试的补丁可修复该例但无泛化，现有记忆系统未筛查 benchmark gaming。
- **解决方案**：每轮对话追加用户记录并允许偏好覆盖/遗忘；编码智能体从失败轨迹提补丁，第二模型家族 critic 筛查，冻结 harness 后由固定评测器决定接受。
