## 2609.38147 · Thinking Before Thinking: Scaling Agentic Inference Through Meta-Reasoning
*在思考之前思考：通过元推理扩展智能体推理*

- Paras Dahal, Anton Bakhtin, Taco Cohen, Zhengxing Chen, Carole-Jean Wu, Rob Fergus, Scott Yih, Gabriel Synnaeve, Ruslan Salakhutdinov, Sanjeev Arora, Jason Weston, Anirudh Goyal
- [Abs](https://arxiv.org/abs/2609.38147v1) · [PDF](https://arxiv.org/pdf/2609.38147v1)
- **核心问题**：智能体处理长程复杂问题时，每步的执行控制选择（续用哪部分工作、是否重来、何时停止）缺乏显式推理
- **关键困难**：现有生产编码智能体与直接控制研究框架在长预算下收益饱和，且难以复用先前工作
- **解决方案**：Worker 执行任务级计算，Controller 整合已确立结论、探索候选、按剩余预算评估价值、依持久记忆分派工作，仅携带紧凑运行摘要
- **主要结果**：ProgramBench：GPT-5.5 达 71.5% vs Codex 58.0%，Opus 4.8 达 67.2% vs Claude Code 65.5%；其他基准较直接控制平均提升 3.6–4.2 点
- **未来方向**：小预算时控制器开销可能带来负面影响

## 2609.38108 · Do LLM Agents Execute the Plans They Declare? From Planning-Mode Declaration to Pattern-Specific Execution
*LLM Agent 会执行它们声明的计划吗？从规划模式声明到模式特定执行*

- Subba Reddy Oota, Francisco Herrera, Jordi Cabot Sagrera, Marcos López de Prado, Shadab Khan
- [Abs](https://arxiv.org/abs/2609.38108v1) · [PDF](https://arxiv.org/pdf/2609.38108v1)
- **核心问题**：现有 planner–executor 系统无法区分任务失败是源于规划模式选择错误，还是源于执行不忠实于所声明的计划
- **关键困难**：通用 Plan+ReAct 常无法保持已声明的规划结构，长计划尤甚，且最终任务成功率无法暴露这类结构违背
- **解决方案**：提出 Planning-as-Routing：LLM 只负责声明规划模式，确定性路由器据此调用模式专用执行器，强制维持目标结构，从而分离选择与执行两端
- **主要结果**：ALFWorld 成功率 0.48→0.92，SWE-bench Verified 0.36→0.44；仅 22%–45% 轨迹保持声明结构
- **未来方向**：LLM 仍不能可靠地为各任务选择最强模式，few-shot 仅在部分基准–模型组合上改善模式选择

## 2609.37985 · Merged, Not Measured: An Empirical Study of Performance Issues Fixed by Coding Agents
*合并了，却未测量：编码智能体修复性能问题的实证研究*

- Zhenyu Qi, Haotang Li, Jinfu Chen, Huashan Chen, Yutong Zhao, Derui Zhu, Tomas Cerny, Bo Liu, Sen He
- [Abs](https://arxiv.org/abs/2609.37985v1) · [PDF](https://arxiv.org/pdf/2609.37985v1)
- **核心问题**：编码智能体提交的提速 PR 是否被维护者接受、其性能声明是否真的成立，现有研究几乎无法回答
- **关键困难**：人类性能修复研究未覆盖 agent 修复，维护者拒绝多不说明理由，声明的提速效果无人复现验证
- **解决方案**：以文本过滤加 LLM 与作者编码手册，从 AIDev v4 筛出 1,262 个性能 issue，编码内容与测试，并三 run 重执行 23 个被拒与 30 个已合并修复

## 2609.37953 · Topological Coherence for Self-evolving Multi-agent Systems
*自演化多智能体系统的拓扑一致性*

- Sen Zhao, Ruiqi Kong, Zuyu Zhang, Lifeng Shen, Xinyu He, Xu Zhang, Qinghua Zhang
- [Abs](https://arxiv.org/abs/2609.37953v1) · [PDF](https://arxiv.org/pdf/2609.37953v1)
- **核心问题**：多智能体的责任、交接与记忆边界常与任务依赖不一致，现有联合优化并不保证这种一致性
- **关键困难**：现有方法可联合优化智能体与通信结构，但不要求责任、交接、记忆边界同任务依赖保持对齐
- **解决方案**：将任务图锚定到工具接口，把兼容任务节点组织为可复用责任域，推导依赖驱动与画像条件的协作及边界管控的记忆可见性；在线自演化只保留满足结构约束且提升奖励的耦合变更

## 2609.37834 · Mixture of Self-Improving Branches For Agent Harness Optimization
*面向 Agent Harness 优化的自改进分支混合*

- Haoyu Dong, Yuhang Zhou, Zihao Lin, Yifan Wu, Bo Peng, Mingyi Wang, Xiangjun Fan, Lizhu Zhang, Zhuokai Zhao
- [Abs](https://arxiv.org/abs/2609.37834v1) · [PDF](https://arxiv.org/pdf/2609.37834v1)
- **核心问题**：Harness 优化中递归自改进依赖固定开发集与固定提案策略，搜索沿单一轨迹进行，易收敛到局部最优。
- **关键困难**：固定开发集和提案策略限制了探索方向，各分支无法形成互补能力，难以跳出单条搜索轨迹。
- **解决方案**：每分支保留被本分支更多领先 harness 解决、而非他分支解决的用例，删除所有分支领先 harness 均解决的用例，并用自身搜索历史改写提案策略；路由器按输入选分支头。
- **主要结果**：相对 Meta-Harness：奥数级数学推理 +34.8%，Terminal-Bench 2.0 +11.6%，SWE-bench Lite +3.8%，分支与路由器配置仅用开发数据。

## 2609.37359 · Encore: Few-Shot Agentic Discovery of Manipulation Strategies
*Encore：少样本智能体式操作策略发现*

- Yifan Kang, Zihan Wang, Zhiwen Fan, Bangya Liu
- [Abs](https://arxiv.org/abs/2609.37359v1) · [PDF](https://arxiv.org/pdf/2609.37359v1)
- **核心问题**：机器人任务只给一句指令，未说明如何抓取、接触顺序和期望结果，智能体必须靠试错自行补全这些细节
- **关键困难**：指令省略目标形态时，缺少演示证据的智能体写不出可行程序，试错成本高且无成功信号可依
- **解决方案**：将每个演示转成多视图关键帧、夹爪事件、帧条与完整轨迹组成的证据包；编码智能体据此针对固定感知与动作 API 写策略程序，经少量开发 rollout 迭代后冻结，再做不返回成功信号的密封评测
- **主要结果**：LIBERO-PRO 上首个程序在有演示时成功半数扰动任务、无演示仅 1 个；冻结程序 96.3% 对最强先前智能体系统 89.3%；真实双臂机器人每个任务用 5 个演示学会递方块与倒杯

## 2609.35760 · TokenCast: Forecasting Token Consumption During LLM Agent Execution
*TokenCast：预测 LLM Agent 执行过程中的 Token 消耗*

- Chaoqian Ouyang, Ling Yue, Libin Zheng, Hanghui Guo, Shengxiang Xu, YiShu Wang, Ran Li, Jian Yin, Shaowu Pan, Shimin Di
- [Abs](https://arxiv.org/abs/2609.35760v2) · [PDF](https://arxiv.org/pdf/2609.35760v2) · [Code1](https://github.com/DEFENSE-SEU/TokenCast)
- **核心问题**：同一任务 LLM Agent 的 token 消耗在不同运行间相差一个数量级以上，执行前难以预测且需随运行不断修正
- **关键困难**：下一步由工具反馈与中间结果决定，持续增长的上下文使后续每次调用的输入不断膨胀，总消耗无法先验估计
- **解决方案**：为每个执行段记录自身消耗与引入的上下文增长，组合相邻段得到累积估计并计入重读开销；新观测刷新预测且不调用额外 LLM，SWE-bench Verified 上平均每次运行预测耗时 32.8 ms
- **主要结果**：4 个任务套件、6 个 agent 模型、96 种组合下平均绝对误差较最强基线平均降低 14.5%；离线预算回放中同等轨迹完成度下比固定预算策略平均省 21.3% token

## 2609.37233 · DatalogBench: Evaluating Large Language Models on Text-to-Datalog Synthesis
*DatalogBench：评测大语言模型在文本到 Datalog 合成上的表现*

- Yuan Li, Hanyun Jiang, Guowei Tian, Chengpeng Wang, Peisen Yao
- [Abs](https://arxiv.org/abs/2609.37233v1) · [PDF](https://arxiv.org/pdf/2609.37233v1)
- **核心问题**：现有 Datalog 合成器要求用户提供输入-输出示例，LLM 从自然语言直接生成 Datalog 的能力缺乏系统评测
- **关键困难**：模型会虚构从未声明、类型不一致的辅助谓词，导致编译失败；递归任务上易出现语义错误

- [Abs](https://arxiv.org/abs/2609.31286v1) · [PDF](https://arxiv.org/pdf/2609.31286v1)
- **核心问题**：离线 MARL 冻结策略部署时只执行一次联合动作提议，可能次优，即使邻近存在更优且与行为数据一致的选项
- **关键困难**：一次性部署直接执行固定提议，无法在测试时利用 critic 改进；多智能体修正需协调且不能偏离行为数据太远
- **解决方案**：在测试时对冻结联合策略施加一个全局归一化、投影后的 critic 梯度，协调所有智能体修正，使动作保持可行并接近原提议
- **主要结果**：24 个 MPE 和 SMAC 设置中改进 20 个冻结设置，MPE 平均相对增益 9.2%，SMAC 8.9%，推理延迟仅增约 6%

## 2609.31281 · MA-WAM: Multi-Agent World-Action Model for Test-Time Planning
*MA-WAM：面向测试时规划的多智能体世界-动作模型*

- Guowei Zou, Haitao Wang, Guoxin Wang, Beiwen Zhang, Zhiquan Chen, Guojie Wang, Hejun Wu
- [Abs](https://arxiv.org/abs/2609.31281v1) · [PDF](https://arxiv.org/pdf/2609.31281v1)
- **核心问题**：多智能体需同时执行联合动作且相互影响观测与响应，需用世界模型预测联合动作带来的团队回报
- **关键困难**：将单智能体世界模型逐智能体、逐步预测，无法捕捉多个智能体同时动作之间的依赖关系
- **解决方案**：冻结多智能体流策略，MA-WAM 按跨智能体依赖预测每个候选联合动作的后果，实现高效候选评分以完成测试时规划
- **主要结果**：MAMuJoCo/SMAC/MPE 共30个离线MARL设置：较直接执行提升22.0%，较均匀动作选择提升25.6%

## 2609.30906 · ToolSearcher: Optimizing Tool Selection at Scale via Reinforcement Learning
*ToolSearcher：通过强化学习优化大规模工具选择*

- Zhenlong Dai, Xujie Song, Zitong Wang, Tong Niu, Jian liu, Weiqiang Wang, Xiu Tang, Sai Wu, Chang Yao, Jingyuan Chen · NeurIPS 2026
- [Abs](https://arxiv.org/abs/2609.30906v1) · [PDF](https://arxiv.org/pdf/2609.30906v1)
- **核心问题**：现有工具学习假设工具集小或预定义，真实工具库庞大多样，上下文长度受限下 LLM 难以搜索、区分并组合工具
- **关键困难**：面向知识问答的现有 RL 方法不适配工具选择，无法在搜索时兼顾工具间兼容性，也难以区分功能相似工具
- **解决方案**：以类别约束的工具判别增强相似工具区分度，用事件级搜索建模显式优化多轮搜索中目标工具的发现，并通过轨迹对齐信用分配为搜索-选择各阶段提供细粒度奖励信号
- **主要结果**：在大规模工具选择基准的迭代搜索与复杂工具组合挑战性设置下，持续优于多种强基线
