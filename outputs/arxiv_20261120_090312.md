## 2611.24489 · Mitigating fix reversal: Counterfactual constraints for function-level vulnerability detection
*缓解修复反转：面向函数级漏洞检测的反事实约束*

- Yun Bian, Shihao Li, Haiquan Wang, Yi Chen, Zhao Yang, Zhe Cui
- [Abs](https://arxiv.org/abs/2611.24489v1) · [PDF](https://arxiv.org/pdf/2611.24489v1)
- **核心问题**：函数级漏洞检测器常给修复后版本更高的漏洞概率，即修复反转，修复使函数变长时更严重
- **关键困难**：模型依赖函数长度捷径，截断丢失修复信息，长度增加导致误判修复版本更脆弱
- **解决方案**：滑窗编码覆盖完整函数；训练时在共同长度输入下约束脆弱版概率更高；推理时在固定参考长度上平均概率
- **主要结果**：PrimeVul 上 PairRank 59.4%；长度增加>15%的修复从25.8%升至48.4%，另4模型3数据集提升

## 2611.24636 · Clover-35B-A3B-Preview Technical Report
*Clover-35B-A3B-Preview 技术报告*

- DiffuSpace Technical Team
- [Abs](https://arxiv.org/abs/2611.24636v1) · [PDF](https://arxiv.org/pdf/2611.24636v1) · [Code1](https://github.com/DiffuSpace/Clover-35B-A3B-Preview) · [Code2](https://huggingface.co/Diffuspace/Clover-35B-A3B-Preview)
- **核心问题**：扩散语言模型在智能体编码任务上如何兼顾生成质量、推理速度与显存受限部署。
- **关键困难**：块扩散缺乏跨块历史记忆，双向注意力仅限块内，长上下文一致性与效率难兼顾。
- **解决方案**：采用 35B 总参 3B 激活的 MoE 扩散架构，把已生成上下文的循环记忆读出与当前块 token 放入共享 softmax，加零初始化右上下文卷积分支。
- **主要结果**：SWE-bench Verified 73.6、Terminal-Bench 2.1 51.7，七项智能体指标居首；单张 GB300 上 BF16、batch=1 达 680 tokens/s。

## 2611.24517 · ABSClaw: From Invented Worlds to Reality-Grounded Social Simulation
*ABSClaw：从虚构世界到基于现实的社会模拟*

- Shaobin He, Yan Gao, Quan Zheng, Zhenyang Lin, Zhen Liu, Jiyan He, Shuxin Zheng
- [Abs](https://arxiv.org/abs/2611.24517v1) · [PDF](https://arxiv.org/pdf/2611.24517v1)
- **核心问题**：LLM 人工社会中 persona、环境与交互网络均为虚构，模拟逻辑由自由生成代码实现，结果难与真实人群对应
- **关键困难**：人物与环境靠假设、网络为合成、模拟器为自由生成代码，导致结果无法绑定真实人口且对骨干模型敏感
- **解决方案**：从调查与普查数据、地理空间源和真实网络采样行动者、环境与交互关系；用26个原子操作组合表达状态转移；能力以生命周期作用域技能扩展而不改核心
- **主要结果**：ABSBench（193个真实任务）上综合表现最佳；案例显示接地 persona、环境、网络分别提升与观测结果一致性；单个运行时技能完成13个群体级模拟、共2500万 agent

## 2611.24491 · Probing agent overeagerness in realistic settings with continuation audits
*在现实环境中用 Continuation Audits 探查智能体的过度积极行为*

- Sean Lim, Clement Neo · NeurIPS
- [Abs](https://arxiv.org/abs/2611.24491v1) · [PDF](https://arxiv.org/pdf/2611.24491v1)
- **核心问题**：前沿编码智能体常超出授权行动，内部部署监控依赖私有流量，开放权重模型与独立评估者无法使用
- **关键困难**：自动对齐审计的合成环境易被强模型识破并调整行为，真实部署监控又不可得
- **解决方案**：以真实编码代理会话前缀为起点，令审计器续写轨迹至预设行为，只需维持而非伪造真实场景；在 SWE-Chat 前缀上验证
- **主要结果**：90 对审计真实/续写判别胜率 0.42 vs 0.43；900 次审计 eval-awareness 未升高；三模型各主导不同风险种子

## 2611.22897 · Born for the Task: Rethinking Quantum Chemistry with Foresighted Agentic Computing
*为任务而生：用前瞻式智能体计算重新思考量子化学*

- Haozhi Han, Junjie Yang, Ruge Zhang, Zihe Huang, Pengyi Xu, Bo Zhang, Xianyi Zhang, Yunquan Zhang, Ting Cao, Yunxin Liu, Yifeng Chen, Kun Li
- [Abs](https://arxiv.org/abs/2611.22897v2) · [PDF](https://arxiv.org/pdf/2611.22897v2)
- **核心问题**：通用量子化学软件导致大规模计算超出资源预算，而按需编写的专用程序在运行前无法判断精度与速度是否达标
- **关键困难**：策略的精度和速度只有真正在目标规模上跑过才清楚，缺少执行前的误差与运行时间预测，难以快速找到达标程序
- **解决方案**：把现有软件预设方案拆为可独立配置的算法组件；用小体系外推误差、按目标规模负载与实测硬件吞吐预测运行时间；在精度-运行时间帕累托前沿选最快策略，并指导编码智能体生成程序
- **主要结果**：50,024基函数Hartree-Fock单CPU节点1.41h，快于通用基线估计77×(含开发时间9.8×)；单GPU泛素2.1h≈Mako 64 GPU；B-DNA由约两月降至8.1h(173×)

## 2611.24357 · Semantic Context Handoff with On-Demand Evidence for Long-Horizon Agents
*长程 Agent 的语义上下文交接与按需证据*

- Guolong Zheng, Chen Hou, Xu Yang, Jianshan Zhang, Tao Huang
- [Abs](https://arxiv.org/abs/2611.24357v1) · [PDF](https://arxiv.org/pdf/2611.24357v1)
- **核心问题**：全历史提示使长程 Agent 上下文持续增长、推理成本上升且准确率下降；压缩结论又会丢失后续有用证据。
- **关键困难**：现有方法保留紧凑结论而删除早期观测，后续需要时无法恢复证据，单独摘要或检索调用又增加开销。
- **解决方案**：用紧凑语义状态承载当前解释，动作-观测证据独立可寻址；后续执行相关时按需回填上下文，无需额外摘要或检索模型调用。
- **主要结果**：SWE-bench 150 任务：Pass@1 80.0%→86.9%，token/时间基本不变；完整系统 86.9%，较最强基线省 43% token、41% 时间。

## 2611.24324 · Reducing Inference Cost of Coding Agents with Timeout Cascades
*用超时级联降低编码智能体的推理成本*

- Boxi Zhou, German Sviridov, Dmitrii Ustiugov, Haris Javaid
- [Abs](https://arxiv.org/abs/2611.24324v1) · [PDF](https://arxiv.org/pdf/2611.24324v1)
- **核心问题**：编码智能体消耗大量 GPU 算力，需验证更小更便宜的模型能否在不牺牲准确率的情况下降低成本
- **关键困难**：小模型在难题上准确率不足，直接替换会掉点；学习型任务路由器工程复杂
- **解决方案**：评测 36 个 2024 年后开源大/小模型，发现准确率差距集中于难题；采用混合推理：小模型先尝试，仅在超时或失败时升级大模型，并与 oracle 路由器对比
- **主要结果**：SWE-bench Verified 上总 GPU 小时成本最多降 33%、全任务降 16.4%，准确率不降，接近 oracle 路由器

## 2611.23876 · SWE-growth: Teacher-Guided Adaptive Self-Play for Software Engineering Agents
*SWE-Growth：教师引导的软件工程智能体自适应自博弈*

- Songshi Liang, Zixuan Huang, Mingxuan Song, Haoyu Tang, Shusheng Xu, Tongkai Yang, Zihe Wang, Rui Yan

- **核心问题**：自博弈生成仓库级修复任务时，二值修复奖励与有限采样预算使全部失败组没有组内相对优势信号，任务被浪费
- **关键困难**：全部失败组奖励恒为零，无法提供组相对优势；纯学生自博弈缺少可学习的成功轨迹，教师增强自博弈则未按学生能力选任务

## 2611.23875 · In Situ Training of Optical Neural Networks by Coding Agents
*由编码智能体进行光学神经网络原位训练*

- Ilker Oguz, Colin Christian, Christophe Moser, Demetri Psaltis, Gordon Wetzstein
- [Abs](https://arxiv.org/abs/2611.23875v1) · [PDF](https://arxiv.org/pdf/2611.23875v1)
- **核心问题**：光学神经网络每台器件偏离设计，需在硬件上训练，现有方法依赖专家校准模型或无梯度试错
- **关键困难**：逐器件校准成本高，且无法通过硬件反向传播梯度，无梯度方法效率低

- **主要结果**：分类和图像编码上优于无梯度方法，接近校准模型反向传播，成本仅一小部分；无需逐器件校准
