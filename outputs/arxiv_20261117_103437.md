## 2611.19199 · What Moves a LoCoMo Score? Memory Context, Answer Prompts and Judges
*什么在左右 LoCoMo 分数？记忆上下文、回答提示与评判者*

- Nikhil Kumar Jha, Amitoj Cheema
- [Abs](https://arxiv.org/abs/2611.19199v1) · [PDF](https://arxiv.org/pdf/2611.19199v1) · [Code1](https://github.com/becos-ai/locomo-results)
- **核心问题**：已发布的 LoCoMo 分数把记忆质量与回答提示、评判者、基线配置等很少同时报告的选择混在一起
- **关键困难**：仅换提示或评判者即可造成数分漂移，跨论文分数不可比，无法判断增益来自记忆还是评测配置
- **解决方案**：固定10段对话1540题，交叉2个回答模型、2种提示、3个LLM评判者，与同条件重跑的全对话基线对比，并对150条答案做人工盲检
- **主要结果**：仅换评判者分数最多变7.2分、仅换提示最多变9.3分；gpt-4o-mini下79.7对73.0、88.8对77.5，gpt-4.1-mini下约持平（83.2对83.1）
- **未来方向**：Becos配置在LoCoMo上开发，无留出集，需独立数据验证泛化

## 2611.18890 · Benchmark Factory: Agentic Benchmark Creation via Dataset Curation and Label-Free Quality Anchors
*Benchmark Factory：通过数据集整理与无标签质量锚点实现智能体基准创建*

- Shervin Shahidi, James Poon, Hang Xie, Kenneth O. Xu, Robin Håkanson, Vikram Nair, Jens Pillgram-Larsen, Nachiappan Nagappan
- [Abs](https://arxiv.org/abs/2611.18890v1) · [PDF](https://arxiv.org/pdf/2611.18890v1)
- **核心问题**：团队部署编码智能体需要基于自有代码构建基准，但人工整理与验证成本高，未验证基准会静默误导。
- **关键困难**：人工构建需逐任务标签和审阅，候选基准的失败原因难定位，低质量基准难以自动识别。
- **解决方案**：自主元智能体循环含人工检查点：对真实代码变更生成采集查询，用已知强弱模型跑候选并诊断失败，迭代改写查询、提示与配置，直至通过无需逐任务标签的质量锚点。
- **主要结果**：5% 抽样评分 2.3/2.6；新配置上 Opus 4.7 高推理 60.6% vs 54.4%（p=0.002），GPT-5.5 65.8% vs GPT-5.4 60.5%（p=0.004）；10 个队列比较 9 个同向。
- **未来方向**：质量锚点是必要非充分条件，旨在将人工审查聚焦于循环无法修复之处。

## 2611.18443 · HerAgent: A Block-Level Checkpointing Harness for Coding-Agent Environment Setup
*HerAgent：面向编码智能体环境搭建的块级检查点执行框架*

- Xiang Li, Siyu Lu, Federica Sarro, Claire Le Goues, He Ye
- [Abs](https://arxiv.org/abs/2611.18443v1) · [PDF](https://arxiv.org/pdf/2611.18443v1)
- **核心问题**：编码智能体需先搭建可执行环境，现有搭建按单命令或整脚本控制进度，出错后难以恢复
- **关键困难**：恢复粒度过细无法清除被污染状态，过粗又会丢失已完成的有效进度
- **解决方案**：引入语义 setup block 作为唯一进度控制抽象，围绕块进行执行、校验、检查点、修复与回滚，实现块级恢复
- **主要结果**：四个环境搭建数据集上均优于六个先前智能体：Installamatic-Bench 52.0%→85.0%，SetupBench 46.3%→70.4%，成本最多降 94.5%

## 2611.18293 · PrivacyPR: A Dataset of Real-World Privacy Fixes for Benchmarking Privacy-Aware Code Review
*PrivacyPR：用于隐私感知代码审查基准测试的真实世界隐私修复数据集*

- Hua Yang, Aditya Bhardwaj, Shidong Pan, Bowen Xu
- [Abs](https://arxiv.org/abs/2611.18293v1) · [PDF](https://arxiv.org/pdf/2611.18293v1)
- **核心问题**：编码智能体能否发现GDPR相关隐私缺陷，缺乏真实修复数据与审查基准
- **关键困难**：现有数据集少将真实隐私缺陷、被接受的修复与审查上下文关联，难以测试
- **解决方案**：收集1,469仓库的4,131个合并PR，LLM标注隐私相关性、修复类型与GDPR原则，人工校验250+250，评测时回滚修复重现缺陷
- **主要结果**：Small上，通用提示仅检出42-51%缺陷，显式要求查隐私达88-91%，非修复PR误报11-15%

## 2611.18130 · JFinBench: A Continuously Refreshable Japanese Financial Benchmark from the Latest Certification Exams
*JFinBench：基于最新认证考试的可持续刷新日语金融基准*

- Issa Sugiura, Taro Makino, Takashi Ishida
- [Abs](https://arxiv.org/abs/2611.18130v1) · [PDF](https://arxiv.org/pdf/2611.18130v1)
- **核心问题**：现有金融基准对国家特定金融体系覆盖不足，且题目泄入训练数据后难以保持更新
- **关键困难**：各认证考试格式异构，人工构建与维护成本高，公开题目易被训练数据污染而失效
- **解决方案**：人机协同智能体流水线：编码智能体编写考试专属格式转换代码和复核页，人工验证每题并把修正反馈给智能体，实现异构考试适配与定期刷新
- **主要结果**：6项2026版考试共321题；Claude Fable 5、GPT-6 Astra超93%，最佳开源模型低12个百分点，加工具后仍差约4分

## 2611.18078 · TelePhysica: Agentic Reconstruction of Physically Interactive Scenes
*TelePhysica：物理交互场景的智能体化重建*

- Ruiqi Shu, Xufeng Zhan, Yuanzhi Liang, Haibin Huang, Chi Zhang, Xuelong Li
- [Abs](https://arxiv.org/abs/2611.18078v1) · [PDF](https://arxiv.org/pdf/2611.18078v1)

- **关键困难**：图像到视频扩散耦合像素与隐式运动，无法保持 3D 力学平衡与反事实力控；单遍程序化重建的深度与支撑间隙欠约束，场景会穿插或坍塌
- **解决方案**：视觉语言编码智能体生成可分离网格与声明式物理模型，经轮廓与零力平衡校验后编译为耦合刚体、铰接链、同维布料壳与四面体弹性体的统一求解器，仿真轨迹以像素对齐结构流条件化视频扩散模型

## 2611.17811 · AI Reviews Are Biased Towards the Appendix
*AI 评审偏向附录*

- Saptarshi Ghosh, Mohammad Saim, Tianyu Jiang
- [Abs](https://arxiv.org/abs/2611.17811v1) · [PDF](https://arxiv.org/pdf/2611.17811v1) · [Code1](https://github.com/cincynlp/review_appendix)
- **核心问题**：LLM 评审与人类评审的弱点分别来自论文哪一部分尚不清楚，尤其是否过度依赖附录
- **关键困难**：已有工作主要比较 LLM 与人类评审的整体一致性，未细粒度定位弱点出自正文还是附录
- **解决方案**：抽取 ACL、EMNLP、COLM、ICLR 的 2,000 篇论文，比对 GPT/Claude 与人类评审弱点的章节来源，覆盖 API、编码代理、网页访问三种方式
- **主要结果**：GPT/Claude 约 50% 或以上评审弱点来自附录，人类仅 8.4%；LLM 关注附录深处细粒度技术细节

## 2611.17776 · Certified Improvements to Best-Known Thomson-Problem Configurations with a Search Pipeline Built with Large Language Model Agents

- Hui Shao, Tao Wang, Xiaotian Liu, Yijie Peng
- [Abs](https://arxiv.org/abs/2611.17776v1) · [PDF](https://arxiv.org/pdf/2611.17776v1)
- **核心问题**：Thomson 问题已知最佳构型来自 Cambridge Cluster Database，需找到并认证更低能量的 N=912、1382、2502 构型。

- **解决方案**：从数据库构型出发运行无约束复本交换盆地跳跃，共享极小池、按几何重标号后重组改进区域、仅梯度 polishing，并用精确整数算术认证候选。

- **未来方向**：仅三个 N 的改进，依赖数据库起点；未评估全局最优性或更大规模。

## 2611.17682 · Agent-written heuristics versus commercial solvers on unsolved job-shop benchmark instances

- **核心问题**：前沿 LLM 编码代理仅用开源工具，能否在困难 job-shop 调度上达到商业求解器的质量与速度。

## 2611.17662 · Learn then Bet: Learning Interpretable Rules for Reliable Agent Intervention
*先学习再下注：学习可解释规则以实现可靠的智能体干预*

- You-Lin Chen, Xinyi Lisa Chen, Pedro Herrero-Vidal, Xiaojing Yu, Bingqing Song, Bin Xu
- [Abs](https://arxiv.org/abs/2611.17662v1) · [PDF](https://arxiv.org/pdf/2611.17662v1)
- **核心问题**：turn limit、关键词过滤等运行时启发式会误停本可成功的轨迹、放过失败轨迹
