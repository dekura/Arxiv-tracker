## 2610.22341 · 3DCodeVerse: Exploring 3D Worlds as Code
*3DCodeVerse：将 3D 世界作为代码探索*

- Yipeng Gao, Ziyao Zeng, Jinfa Huang, Yijiang Li, Haolin Xiong, Wang Qin, Xinlei Yu, Youheng Yao, Jie Zhang, Kun-Yu Lin, Rong Liu, Yinyuan Zhao, Yajie Zhao, Meiqi Guo, Jiebo Luo, Lei Shu, Yunhao Ge, Xinyu Hu, Laurent Itti
- [Abs](https://arxiv.org/abs/2610.22341v1) · [PDF](https://arxiv.org/pdf/2610.22341v1)
- **核心问题**：如何让编码智能体大规模生成可编辑、可验证的 3D 内容，并缺乏相应数据与自动验证手段。
- **关键困难**：3D 代码数据稀缺、跨环境依赖复杂，生成结果难以自动判断几何正确性与可执行性。
- **解决方案**：构建 3DCodeVerse-2M 可执行 3D 代码数据集（含源文件、资产、描述与验证记录），并开发多智能体 DAG harness 自动评估与修订程序。
- **主要结果**：在自建数据集上微调显著提升开源模型 3D 编码能力；harness 在与 Claude Design（3D Object）成对人工评测中取得 90% 胜率。

## 2610.22324 · Training Reasoning Models to Generate Diverse Scientific Ideas
*训练推理模型生成多样化的科学想法*

- Manya Wadhwa, Pranav Narayanan Venkit, Hiroaki Hayashi, Yu Li, Tuhin Chakrabarty, Chien-Sheng Wu
- [Abs](https://arxiv.org/abs/2610.22324v1) · [PDF](https://arxiv.org/pdf/2610.22324v1) · [Code1](https://github.com/ManyaWadhwa/diverge_ideation)
- **核心问题**：LLM用于研究流程第一步的想法生成时普遍只优化单个想法质量，忽视多样性，而实际需要一组既高质量、彼此明显不同、又扎根于输入文献的想法
- **关键困难**：逐点质量优化导致想法同质化，多样性缺乏可训练的信号，难以在提升多样性的同时不损失质量与可执行性
- **解决方案**：单次生成K张基于源文献的结构化想法卡，对整组联合打分，其中每个想法的质量以它与之前已写想法的距离加权，从而训练模型把每个新想法推离前作
- **主要结果**：8B模型在无污染基准上的创造性效用超过Claude Opus 4.8与GPT-6 Astra；4位专家评测中集合前景相当、独特想法略多；编码智能体概念验证实验的success@k相当

## 2610.22289 · Improving Environment-Agnostic Coding Agents: The Role of Scaffolding
*改进环境无关的编程智能体：脚手架的作用*

- Sergey Rodionov
- [Abs](https://arxiv.org/abs/2610.22289v1) · [PDF](https://arxiv.org/pdf/2610.22289v1)
- **核心问题**：更强模型是否仍需开发者提供的脚手架，环境无关智能体能否不经环境特化工程而改进
- **关键困难**：通用智能体在 ARC-AGI-3 上低于专用参考，而该参考只规定组织与控制、不给新规则，难区分信息可得与有效使用
- **解决方案**：在两个近乎相同提示变体上评测同一 Codex 智能体，跨环境统一代码、提示与通用工具；并把 reset 决策交给遵循既定约定的脚本控制器
- **主要结果**：ARC-AGI-3 与 AGI Maze 平均分提升，Terminal-Bench 变化小且混杂；脚本控制器接管 reset 可挽回部分专用优势，token 成本更高
- **未来方向**：实验未把信息与流程的更好使用同额外或重新分配的推理分开；性能增益伴随更高 token 成本

## 2610.18845 · The Last Remote Sensing Model Built by Humans? Casting Any Earth Observation Task as Recursive Self-Improvement
*人类构建的最后一个遥感模型？将任意地球观测任务转化为递归自我改进*

- Sijie Zhao, Zeqi Zhou, Heli Qi, Xuanchao Fu, Zhuo Zheng, Junshi Xia, Junjue Wang, Weihao Xuan, Naoto Yokoya
- [Abs](https://arxiv.org/abs/2610.18845v2) · [PDF](https://arxiv.org/pdf/2610.18845v2)
- **核心问题**：地球观测模型仍靠人工为每个新任务设计训练配方并调参，少样本、跨域等被当作独立问题，缺乏统一自动化范式
- **关键困难**：验证信号因任务而异，传统方法需为每个EO任务单独设计训练流程，无法复用统一的agent循环
- **解决方案**：用harness定义可用资源，verifier定义成功；借助标注基准、独立传感器、物理模型或重复观测使任务可验证，通用编码智能体据此递归构建并自我改进EO模型
- **主要结果**：四个EO基准（光学、SAR、多光谱时序）上，agent构建模型超越SOTA，用约1%训练标签保持大部分精度
- **未来方向**：项目持续进行中，未提及具体局限与未来工作

- [Abs](https://arxiv.org/abs/2610.22039v1) · [PDF](https://arxiv.org/pdf/2610.22039v1)

## 2610.21914 · CodeHealth Predicts the Token Cost of Agentic Code Review: A Pre-Registered Study of 465 Agent-Authored Pull Requests

- [Abs](https://arxiv.org/abs/2610.21914v1) · [PDF](https://arxiv.org/pdf/2610.21914v1)

- **解决方案**：从 AIDev 的 246 个仓库按 CodeHealth 与 footprint 联合分层抽样 465 个 PR，冻结五智能体审查修复流水线配三个 LLM 处理，拟合带仓库随机截距的 log token 混合模型

## 2610.20003 · What Coding Agents Leave Unsaid: Measuring Task-State Gaps Between Execution and Reports
*编码智能体未言明之事：度量执行与报告之间的任务状态差距*

- Guoyang Xu, Rui Zhang, Xiuyu Wu, Hao Chen
- [Abs](https://arxiv.org/abs/2610.20003v2) · [PDF](https://arxiv.org/pdf/2610.20003v2)
- **核心问题**：监督者只能依赖编码智能体的报告判断进度与是否介入，而失败尝试、变通做法和未解决风险常从例行报告中消失
- **关键困难**：报告是监督者唯一信息渠道，未被报告的失败无法被调查；状态虽被提及却缺乏支撑细节，监督相关信息也大量缺失
- **解决方案**：CTXGAP 在 37 个编码任务上用 4,799 个探针询问任务状态，对比仅报告、完整终端回滚与完整上下文的恢复率，并做人工标注与上下文知情改写对照
- **主要结果**：仅报告读者恢复 52.0%，完整上下文 92.7%，差 40.7 点；30 个已验证修复终检点差 34.8 点；终端回滚仅 73.6%
