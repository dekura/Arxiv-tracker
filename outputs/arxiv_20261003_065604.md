## 2610.02163 · AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents
*AutoCompact：学习何时在长程编码智能体中压缩上下文*

- Xuan Zhang, Longtao Zheng, Cunxiao Du, Bo An, Xin Dong
- [Abs](https://arxiv.org/abs/2610.02163v1) · [PDF](https://arxiv.org/pdf/2610.02163v1)
- **核心问题**：长程编码轨迹中早期探索信息过期，智能体需决定何时压缩上下文、保留哪些工作状态及如何继续
- **关键困难**：压缩不只是避免溢出，现有方法未把压缩决策纳入策略，易丢失关键状态或从错误状态继续
- **解决方案**：运行基础智能体，用裁判审查压缩决策、摘要与压缩后动作，修正后再在环境执行得轨迹；先 SFT，再用任务成功奖励联合优化编码与压缩
- **主要结果**：SWE-bench Verified 与 SWE-PolyBench Verified 的 pass rate 绝对提升 9.2% 和 5.0%，各推理预算下均改善

## 2610.01769 · CONTRA: Discovering and Qualifying Behavior-Changing Questions for Selective Clarification in LLM Code Generation
*CONTRA：为 LLM 代码生成中的选择性澄清发现并鉴定改变行为的问题*

- Zheng Fang, Yongmin Li, Yichang Zhang, Dongming Jin, Haoyu Wang, Shuai Wang, Zhi Jin, Ge Li
- [Abs](https://arxiv.org/abs/2610.01769v1) · [PDF](https://arxiv.org/pdf/2610.01769v1) · [Code1](https://github.com/fangz-cs/Contra)
- **核心问题**：编码代理静默以自身假设填补欠明确需求，产出用户未预期的行为，后续开发继承该假设后修正代价高
- **关键困难**：既要找出关键澄清问题，又要避免多余提问打断开发者、拖慢开发，现有方法难以同时兼顾
- **解决方案**：先生成候选问题，过滤与所需行为无关或已被需求解决的；对余下问题分别以两个合理答案生成程序，在共享输入上检验稳定行为差异，再依交互历史选择提问或停止
- **主要结果**：ClarifyCodeBench 上四个编码代理 F1 均最高，超最佳基线宏平均 F1 13.88 个百分点；同 LLM 与评测协议下澄清召回率与 F1 高于 Claude Code、OpenHands

## 2609.38269 · Zero2Repo: Can Coding Agents Build Repositories from Scratch?
*Zero2Repo：编码智能体能从零构建仓库吗？*

- Pei Yang, Tianyu Shi, Yuhang Yao, Wanyi Chen, Tongyun Yang, Dun Pei, Haonan Wang, Pengbin Feng, Guanxu Yu, Jingchun Huang, Zeyu Zhang, Shuhan Sun, Hao Li, Alex Gu, Xiang Li, Jie Xiao, Xinyu Wang, Hanxin Chen, Daqi Li, Qi Jia, Hongshan Lin, Zhizhou Gu, Zijun Tian, Weizhi Du, Lynn Ai, Eric Yang
- [Abs](https://arxiv.org/abs/2609.38269v2) · [PDF](https://arxiv.org/pdf/2609.38269v2)
- **核心问题**：现有从零构建仓库的评测基准多局限于单一编程语言，且依赖人工挑选和构造任务
- **关键困难**：缺少语言无关、可执行验证的自动化出题方式，难以可靠衡量智能体在多生态中完整交付仓库的能力
- **解决方案**：以版本固定的真实开源项目为源，经语言无关流水线生成行为规格、可复现环境与隐藏验收测试；参考实现必须通过、对抗验证必须拒绝错误实现；容器内隔离运行，提交前不公布测试，全部测试通过才给二元奖励
- **主要结果**：在 11 个可能已被前沿模型见过的仓库任务上，最强智能体仅解出 10 个；所有失败提交通过 90-99% 隐藏测试；两个最强智能体中 67-100% 的失败测试源于单处遗漏或规格中的低频规则

## 2610.01618 · Agents Are Systems, Not Models: Rethinking Agentic Evaluation
*智能体是系统，而非模型：重新思考智能体评估*

- Luis Wiedmann, Leander Girrbach, Cordelia Schmid, Zeynep Akata
- [Abs](https://arxiv.org/abs/2610.01618v1) · [PDF](https://arxiv.org/pdf/2610.01618v1)
- **核心问题**：现有智能体评测把智能体当作固定模型，只报成功率等指标，忽略配置选择对表现与稳定性的影响
- **关键困难**：配置选择相互耦合且存在大量 run-to-run 方差，难以区分模型能力与系统配置各自带来的差异
- **解决方案**：在四个科学任务新基准上系统改变五类配置进行对照实验，用基于轨迹的行为分类法分析验证行为，并公开超过 18,000 条智能体轨迹
- **主要结果**：约 54% 的结果方差来自重复同一配置；任务信息影响最大，超过时间预算与模型规模，同时降低成本、改善校准；时间仅在信息充足或模型足够强时有帮助

## 2610.01508 · OverAct: Measuring and Mitigating Proactive Over-Authorization in LLM Tool-Calling Agents
*OverAct：测量与缓解 LLM 工具调用智能体中的主动过度授权*

- Taolin Zhang, Jiuheng Wan, Hanyu Wang, Tingyuan Hu, Chengyu Wang
- [Abs](https://arxiv.org/abs/2610.01508v1) · [PDF](https://arxiv.org/pdf/2610.01508v1)
- **核心问题**：LLM 工具调用智能体常检索超出用户请求所需的信息，即主动过度授权，缺乏系统度量与缓解手段
- **关键困难**：结构化工具调用的核心风险是私有数据的非必要访问，授权边界依赖请求语义，难以静态判定
- **解决方案**：构建覆盖八个隐私敏感域、确定性免评判打分的受控基准 OverAct；SelfAudit 在推理时生成以请求为依据的辩护，执行前过滤无正当理由的调用
- **主要结果**：四家族七个模型均显著超出授权范围；请求具体性是最强预测因子，过度授权随工具池规模亚线性增长，温度影响甚微；SelfAudit 无 oracle 知识下减少 43% 隐私性超额，消融显示显式过滤是主因

## 2610.01108 · AgSpec: Pushing the Limits of Retrieval-Based Speculative Decoding in Coding Agent Pipelines
*AgSpec：在编码智能体流水线中推动基于检索的推测解码的极限*

- Sumin Lee, Sukmin Cho, Suengjae Lim, Youngjin Kwon
- [Abs](https://arxiv.org/abs/2610.01108v1) · [PDF](https://arxiv.org/pdf/2610.01108v1)
- **核心问题**：现有检索式推测解码在编码智能体流水线中可复用文本缺失或格式不一致，草稿长度未随智能体与轮次变化
- **关键困难**：语料库缺少可复用文本，存储格式与智能体输出不一致，固定草稿长度无法适应不同智能体及轮次漂移
- **解决方案**：从会话、工作区、全局三层语料检索，并按智能体输出格式索引打开文件；用离线画像的每智能体草稿长度上限，并依据验证反馈在线调整长度
- **主要结果**：两个仓库级多智能体编码基准上超越五种检索式 drafter 与 EAGLE-3，batch 1 吞吐达 4.37×，batch 16 达 4.76×

## 2610.01048 · Network World Models as Environments for Algorithm Design on Complex Systems
*网络世界模型作为复杂系统算法设计的环境*

- Rishab Alagharu, Hongji Pu, Zeeshan Memon, Xinyuan Song, Yuntong Hu, Liang Zhao

- **关键困难**：模拟评估候选需采样大量轨迹，计算成本成为算法设计循环的瓶颈
- **解决方案**：学习网络在干预下的扩散动态，用世界模型预测动作后果替代模拟；编码智能体依据完整 rollout、动作级信用与反事实探针迭代改进可执行算法
- **主要结果**：8 个网络任务、5 种扩散模型下，141 个设定中 138 个匹配或超越最强基线，rollout 比蒙特卡洛模拟快至多 14.5 倍

## 2610.01023 · Groundability, Not Scale Alone: When Weak Reviewers Can Audit Strong Coding Agents
*可审计性而非仅规模：弱审查者何时能审计强编码智能体*

- Junyu Guo, Shangding Gu, Ming Jin, Javad Lavaei
- [Abs](https://arxiv.org/abs/2610.01023v1) · [PDF](https://arxiv.org/pdf/2610.01023v1)
- **核心问题**：弱审查者能否可靠判断强编码智能体给出的补丁是否真正解决了对应 issue
- **关键困难**：长执行轨迹与自信摘要掩盖遗漏行为，且部署环境缺少官方测试作为判据
- **解决方案**：用411条执行标签轨迹与101个受控案例评测审查者；为每个审查者选定并冻结一种证据格式；再构建含补丁静态错误与首次在未修复仓库失败生成测试的冻结级联
- **主要结果**：冻结格式后6个审查者中5个在122条测试集上捕获与误拒双改善，2个全对；级联在GPT-5.4上覆盖0.89、风险0.33、捕获0.76、误拒0.66
- **未来方向**：无官方测试时如何产生同等可靠的检查仍是主要瓶颈
