## 2610.31511 · DuoCook: An Overcooked-Inspired Benchmark for Visual Planning and Coordination
*DuoCook：受 Overcooked 启发的视觉规划与协调基准*

- Ziyi Jiao, Heng Zhang, Drishti Regmi, Xiaokang Ye, Lianhui Qin, Peter Yichen Chen
- [Abs](https://arxiv.org/abs/2610.31511v1) · [PDF](https://arxiv.org/pdf/2610.31511v1)
- **核心问题**：在烹饪任务中协调两名玩家，需跟踪动态场景、排序菜谱步骤并在时限内分配共享资源
- **关键困难**：单一视觉语言模型需从俯视视觉同时控制双玩家，处理设备争用、地形变化与交接依赖
- **解决方案**：编码智能体在Unreal Engine构建20张五类地图；单VLM从俯视观测选高层动作、引擎执行导航；提供道具图例、锅食材计数和网格目标，并做四模型与共享笔记本消融
- **主要结果**：最强gpt-6-astra平均订单完成率26.2%；共享笔记本记忆对Claude/Qwen得分正、对GPT/Gemini负

## 2610.31461 · Adaptive Skill Granularity for Coding Agents: Runtime Routing and Macro-to-Micro Recovery
*面向编码智能体的自适应技能粒度：运行时路由与宏到微恢复*

- Dingxuan Zhang, Yanhui Jiang, Jun Wang, Hefeng Zhou
- [Abs](https://arxiv.org/abs/2610.31461v1) · [PDF](https://arxiv.org/pdf/2610.31461v1)
- **核心问题**：编码智能体执行时该用原始工具调用、宏技能还是混合执行，缺乏运行时控制
- **关键困难**：固定宏执行在适用时高效但易在任务不匹配时失效，且无法恢复受控宏失败
- **解决方案**：特征驱动的粒度控制器结合有限状态恢复执行器，在运行时选择宏、微或混合路径，并对宏失败显式触发微级回退
- **主要结果**：固定宏执行适用时高效但失配时脆弱；运行时路由与宏到微恢复提升鲁棒性，可恢复固定粒度遗留的受控宏失败

## 2610.31276 · RIPPLE: Recovery Internalization through Process-Level Policy Learning and Effect-Aware Credit for Long-Horizon Agentic Coding
*RIPPLE：通过过程级策略学习与效果感知信用实现长程智能体编码的恢复内化*

- Jingxuan Xu, Zihang Xu, Yuechen Luo, Ziqi Miao, Wenqiang Zhu, Weihao Li, Junhao Fan, Xinshun Feng, Zhiyi Lai, Yanan Wu, Haoyang Huang, Ken Deng
- [Abs](https://arxiv.org/abs/2610.31276v1) · [PDF](https://arxiv.org/pdf/2610.31276v1)
- **核心问题**：长程编码智能体能看出失败并给出批评，却仍沿同一错误轨迹继续执行
- **关键困难**：现有训练只按终端结果给信用，中间反思与诊断决策缺乏区分性监督，批评难转化为行动
- **解决方案**：仅前缀可见的教师给出有证据依据的恢复监督，轻量蒸馏后用 RL 对反思触发、诊断与纠正行动分阶段分配信用，并以局部有效性信号门控轨迹优势
- **主要结果**：四个仓库级软件工程基准平均提升 4.8 分，部署时无需辅助 critic；匹配前缀干预显示批评语义影响后续纠正
- **未来方向**：恢复收益依赖前缀含足够诊断证据且剩余预算内仓库状态可逆

## 2610.30571 · Stale Instruction Files Override the Code in Coding Agents: A One-Sentence Fix
*过时指令文件会覆盖编码代理中的代码：一句修复*

- Xiaonan Xu, Wenjing Wu
- [Abs](https://arxiv.org/abs/2610.30571v1) · [PDF](https://arxiv.org/pdf/2610.30571v1) · [Code1](https://github.com/WenJing95/stale-docs-data)
- **核心问题**：编码代理会遵循过时的项目指令文件，即使它与现有代码冲突且代理已察觉
- **关键困难**：指令文件以指令形式输入，代码仅作为工具输出，模型被训练为更重视前者
- **解决方案**：构建40个指令与代码约定冲突的Python项目，在Claude Code和Codex CLI的320次运行中测试用户级指令文件加入“现有代码优先”一句的效果

- **未来方向**：用户可立即添加该句；代理与模型厂商可将规则内置产品

## 2610.30284 · SWE-VERIFIER: Selective Verification for Cost-Efficient Coding Agents
