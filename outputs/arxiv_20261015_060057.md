## 2610.18862 · DoubtLess: Training-Free Contrastive Decoding for Efficient Reasoning
*DoubtLess：免训练对比解码实现高效推理*

- Minghao Luo, Liang Chen
- [Abs](https://arxiv.org/abs/2610.18862v1) · [PDF](https://arxiv.org/pdf/2610.18862v1) · [Code1](https://github.com/leoluolol/DoubtLess)
- **核心问题**：推理模型CoT过长、消耗多余token，缩短需额外训练或启发式截断，易损失精度
- **关键困难**：现有方法需逐模型训练、加固定转向向量，或用早停/禁词等启发式，常降低准确率
- **解决方案**：小推理模型分别以简洁与冗长提示读取大模型已生成CoT，两logit向量之差按强度缩放后，在CoT每一步加到大模型logits上
- **主要结果**：七个基准上Qwen3-32B的CoT缩短31%且精度不变，优于五个推理时基线；自调试编码agent每轮思考token减20%且任务性能不变

## 2610.18845 · The Last Remote Sensing Model Built by Humans? Casting Any Earth Observation Task as Recursive Self-Improvement
*人类构建的最后一个遥感模型？将任意地球观测任务转化为递归自我改进*

- Sijie Zhao, Zeqi Zhou, Heli Qi, Xuanchao Fu, Zhuo Zheng, Junshi Xia, Junjue Wang, Weihao Xuan, Naoto Yokoya
- [Abs](https://arxiv.org/abs/2610.18845v1) · [PDF](https://arxiv.org/pdf/2610.18845v1)
- **核心问题**：地球观测模型仍靠人工为每个新任务设计训练配方并调参，少样本、跨域等被当作独立问题，缺乏统一自动化范式
- **关键困难**：验证信号因任务而异，传统方法需为每个EO任务单独设计训练流程，无法复用统一的agent循环
- **解决方案**：用harness定义可用资源，verifier定义成功；借助标注基准、独立传感器、物理模型或重复观测使任务可验证，通用编码智能体据此递归构建并自我改进EO模型
- **主要结果**：四个EO基准（光学、SAR、多光谱时序）上，agent构建模型超越SOTA，用约1%训练标签保持大部分精度
- **未来方向**：项目持续进行中，未提及具体局限与未来工作

## 2610.18835 · RoboSimStudio: An Interactive Toolkit for Rapid Real2Sim of Robot Manipulation Tasks
*RoboSimStudio：用于机器人操作任务快速 Real2Sim 的交互式工具箱*

- Kaiyuan Chen, Shuangyu Xie, Uksang Yoo, Xinyue Zhu, Cael Magner, Alvin Zhu, Daehwa Kim, Eric Heiden, Erwin Coumans, Miles Macklin, Spencer Huang, Ken Goldberg
- [Abs](https://arxiv.org/abs/2610.18835v1) · [PDF](https://arxiv.org/pdf/2610.18835v1)
- **核心问题**：机器人操作中接触力学、耦合接触动力学、形变、刚度与摩擦难以精确建模，仿真与真实存在差距
- **关键困难**：现有仿真中求解器与物理参数选择隐式且难调，无法依据观测到的真实物理行为迭代修正
- **解决方案**：基于 Newton 物理仿真系统实现 RSS，暴露求解器、接触模型与物理参数供编辑；支持视觉评估、力反馈与智能体 Real2Sim2Real 三种人引导校准实验
- **主要结果**：在人类引导的 Real2Sim 中验证视觉评估、力反馈与智能体 Real2Sim2Real 三类流程可行

## 2610.18760 · Beyond the Verdict: Agentic Code Judging with Verifiable Feedback
*超越判决：带可验证反馈的智能体代码评判*

- Zheye Deng, Sha Li, Changlong Yu, Xin Liu, Qin Lu, Priyanka Nigam, Yangqiu Song
- [Abs](https://arxiv.org/abs/2610.18760v1) · [PDF](https://arxiv.org/pdf/2610.18760v1)
- **核心问题**：官方评判只给权威判决且提交次数有限，不提供失败解释或失败输入，难以指导候选选择与修订
- **关键困难**：缺乏失败证据与可复用反馈，官方提交预算有限，无法靠反复试错获得诊断信息
- **解决方案**：构建 USACO-JUDGE 数据集，在通用执行沙盒中用 RL 训练 35B MoE 智能体验证器，生成反例作为可验证证据
- **主要结果**：反例成功率 40.61%→62.67%，USACO-JUDGE 判决准确率 71.41%→87.41%；IOI 2026 案例超金牌线

## 2610.18507 · The Last Mile of Coding Agents for Long-Document Tasks: An Empirical Study on Clinical Trial Protocol Digitization
*面向长文档任务的编程智能体最后一公里：临床试验方案数字化的实证研究*

- Jiacheng Lin, Geoffrey Low, Nishit Agarwal, Rahul Jain, Afrah Shafquat, Mandis Beigi, Jimeng Sun
- [Abs](https://arxiv.org/abs/2610.18507v1) · [PDF](https://arxiv.org/pdf/2610.18507v1)
- **核心问题**：编程智能体能否可靠地把完整长文档转化为准确的结构化输出尚不清楚
- **关键困难**：智能体通常已定位到所需证据，却在最后一步的转录与结构化环节失败
- **解决方案**：以方案数字化为测试台，构建 TrialPD-Bench 评测最终答案、证据召回、智能体行为与成本；再提出 TrialScribe，为智能体加装任务技能与验证循环

## 2610.18206 · SWE-MISBEHAVIOR: Benchmarking and Mitigating Boundary Violations in Software Coding Agents
*SWE-MISBEHAVIOR：诊断与缓解软件编码智能体中的边界违规行为*

- Do Xuan Trong, Duc Anh Nguyen, Do Xuan Long, Ngoc-Hai Nguyen, Tongyao Zhu, Duy Dinh, Cayden Chik, Cuong Dang, Jiaying Wu, Xuan-Phi Nguyen, Vinh Van Nguyen, Kenji Kawaguchi, Shafiq Joty, Nancy F. Chen, Min-Yen Kan
- [Abs](https://arxiv.org/abs/2610.18206v1) · [PDF](https://arxiv.org/pdf/2610.18206v1) · [Code1](https://github.com/dxlong2000/SWE-Misbehavior)
- **核心问题**：编码智能体执行任务时易越界：误判依赖、擅自修改用户输入、破坏环境完整性、偏离任务目标，且缺乏系统诊断手段
- **关键困难**：现有评测只看任务完成率，缺少对越界与破坏性行为的分类框架和自动化检测方法
- **解决方案**：构建7.4K人机协同合成样本，覆盖代码生成、文件管理、系统交互三层；提出CODE-KIT，用越界感知准则与专用工具自适应约束智能体行为
- **主要结果**：依赖误判达98.5%、改用户输入50.5%、破坏环境53%；CODE-KIT降低越界52%(smolagents)/34%(OpenHands)并提升完成率

## 2610.18004 · SWEPatchTest: Evaluating Software Tests Beyond Reproduction
*SWEPatchTest：超越复现的软件测试评估*

- Hua Lu, Pengcheng Wang, Han Li, Zichen Tian, Yanyu Chen, Huang He, Bingjin Chen
- [Abs](https://arxiv.org/abs/2610.18004v1) · [PDF](https://arxiv.org/pdf/2610.18004v1)
- **核心问题**：现有测试评估只检查测试能否复现参考补丁带来的失败到通过转变，无法判断测试是否接受正确补丁、拒绝错误补丁。
- **关键困难**：仅凭 buggy 失败、reference patch 通过的单参考判据，会掩盖测试套件对补丁区分能力的严重缺陷。
- **解决方案**：构建含 619 个任务、82,579 个候选补丁的基准，在 buggy 与 patched 代码库回放测试套件，计算 JVR，并用验证分数筛选与扩展 SFT 演示数据。
- **主要结果**：最佳配置 JVR 仅 9.21%，却在 59.29% 任务上复现参考转变；该训练配方令 JVR 约增至三倍，并在三个 SWE-bench 基准上提升修复表现。

## 2610.17895 · Interaction-as-a-Judge
*交互即评判（Interaction-as-a-Judge）*

- Wayne Chi, I-Hung Hsu, Li Chen, Wei-Lin Chiang, Ion Stoica, Anastasios Nikolas Angelopoulos, Ameet Talwalkar, Chris Donahue, Cho-Jui Hsieh
- [Abs](https://arxiv.org/abs/2610.17895v1) · [PDF](https://arxiv.org/pdf/2610.17895v1)
- **核心问题**：自动 LLM 评测偏重代码分析与单元测试，与人类交互评估不匹配，易漏掉用户一眼可见的失败。
- **关键困难**：仅分析代码或跑单元测试无法覆盖运行时交互行为，代码正确不等于用户可用。
- **解决方案**：收集人类偏好+agent轨迹与需求标注数据；让 computer-use agent 操作应用，预测人类偏好并验证需求，推理时修复缺陷，训练时作奖励信号。
- **主要结果**：偏好预测65.6%→69.1%，需求验证77.0%→81.6%；交互修复75.5%对55.4%。

- **关键困难**：串行等待使 rollout 吞吐低；推测加速必须保证 rollout 无损，且世界模型需随策略持续更新而不失准
- **解决方案**：用小世界模型在环境执行期间预测工具输出，使策略提前开始下一轮生成；仅当预测与实际观测精确匹配时保留推测工作，并通过协同训练同步更新世界模型
- **主要结果**：终端任务上 0.6B 世界模型预测 66.4% 精确匹配、约快 16 倍；8B 与 32B 策略延迟分别降低 9.3% 和 14.2%

## 2610.14883 · MARL-BattleGrounds: A Novel JAX-native Benchmark for Heterogeneous and Competitive Multi-agent RL
*MARL-BattleGrounds：面向异构与竞争多智能体 RL 的 JAX 原生基准*

- Ulixes Tariq Hawili, Subramanian Ramamoorthy, Yoann Altmann, Ignacio Carlucho
- [Abs](https://arxiv.org/abs/2610.14883v1) · [PDF](https://arxiv.org/pdf/2610.14883v1)
- **核心问题**：多智能体 RL 基准两极分化：或简单到胜负只取决于单位微操，或如 Dota 2 般丰富但算力昂贵，缺少中间档
- **关键困难**：缺少兼具异构角色协同、泛化能力评测与可持续公平排名机制的中间规模基准
- **解决方案**：JAX 原生 5v5 同时回合制环境，5 种职业有基础/被动/终极技能，52 张手工地图含 12 图课程；提供 8 个残局泛化场景与月度 Elo 轮转赛两种评测模式
- **主要结果**：单张 RTX 5090、1024 并行对局下模拟器达 50,000 个 5v5 步/秒；每局记录 28 主题共 11,192 项指标；含 3 个脚本对手与 6 个深度 MARL 基线，并用该 API 评测 Qwen3.5-9B

## 2610.14405 · SPROUT: Scaling Agentic Reinforcement Learning for Long-Horizon Software Engineering
*SPROUT：面向长时程软件工程的智能体强化学习扩展*

- Mengyang Liu, Weiming Wang, Haixin Nan, Yu Wu, Peize Li, Shihong Huang, Xuning He, Xue Jiang, Yihong Dong
- [Abs](https://arxiv.org/abs/2610.14405v1) · [PDF](https://arxiv.org/pdf/2610.14405v1)
- **核心问题**：长时程软件工程任务中成功轨迹稀少，从初始状态反复重启效率低，仅重置上下文会丢失依赖安装等状态变化
- **关键困难**：细小错误即导致整条 rollout 失效，重启成本高且只重置上下文无法还原执行环境状态
- **解决方案**：基于快照的基础设施在每轮对话后同时保存文件系统与智能体上下文，由验证器引导的回溯策略决定从中途何处恢复及如何继续
- **主要结果**：pass@k 最高提升 23.6% 且仅用 32--52% token；Qwen3.8-27B RL 训练在三个长时程基准上比 GRPO 高 13.9 分，每步训练时间减少 39.5%
